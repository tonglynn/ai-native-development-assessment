# Attest MCP demo transcript

Generated by `python scripts/mcp_demo.py`: a client talks to `python -m attest.mcp_server` over stdio (the same protocol Claude Code uses). Repository: a fresh copy of ledgerly 1.0.0. Verification command (set by the person who configures the server): pytest on the repository's tests.

## 0. Tools the server offers an agent

```json
// call: list_tools()
[
  "learn",
  "list_notes",
  "recall",
  "report_outcome"
]
```
