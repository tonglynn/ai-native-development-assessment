讲解时要说清的四点：为什么要有长期记忆（规矩散落各处，评审一再重复）；为什么通过测试不代表经验正确（float 毒药能通过测试）；为什么需要人工审核（拿不准的经验由登记的负责人决定，智能体不能自己批准）；实验到底证明了什么（预注册的成长结果；探索性的安全与对照结果，以及各自口径）。

合成旁白与视频：

```
ffmpeg -i docs/attest_walkthrough.mp4 -i narration.m4a -map 0:v -map 1:a -map 0:s? -c:v copy -c:s copy -c:a aac -shortest docs/attest_walkthrough_voice.mp4
```
